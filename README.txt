طريقة النشر في GitHub Pages:
١. افتحي مستودع GitHub جديدًا، وارفعي محتويات هذا الملف المضغوط إلى جذر المستودع (index.html وmanifest.webmanifest وsw.js ومجلد assets).
٢. من Settings ثم Pages اختاري Deploy from a branch ثم main و/(root) واضغطي Save.
٣. بعد النشر افتحي الرابط HTTPS، ومن قائمة المتصفح اختاري إضافة إلى الشاشة الرئيسية أو تثبيت التطبيق.

مهم: النتائج تحفظ محليًا في المتصفح على جهاز المعلمة. لا تنتقل تلقائيا إلى جهاز آخر. احفظي نسخة احتياطية JSON باستمرار.
مراجعة الأهداف قبل الاعتماد الرسمي ضرورية مقابل الكتاب الأصلي.
لا ترفعي ملفات نسخ احتياطية تحتوي أسماء الطلبة إلى GitHub.
